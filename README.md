# 이상현상 퇴마 기록

Unity 6000.3.18f1 / URP 기반의 Windows 64비트, FHD 1920×1080 창 모드 탑다운 2D 게임입니다. [수정 게임기획서](Docs/게임기획서)에 따라 1–5일차, 해피·포획 엔딩까지 이어집니다.

## 실행

- Unity Hub에서 `Unity` 폴더를 프로젝트로 엽니다.
- `Assets/Scenes/Lobby.unity`를 열고 Play를 누릅니다.
- Windows 빌드가 있는 경우 `Builds/Windows/NightCafe.exe`를 실행합니다. 배포할 때는 `Windows` 폴더 전체를 함께 전달합니다.
- Game 뷰는 1920×1080 또는 16:9로 설정합니다. 실행 파일은 FHD 고정 크기 창으로 시작합니다.

## 두 씬

| 씬 | 역할 |
| --- | --- |
| Lobby | 게임 시작 화면, 조작 안내, 종료 |
| InGame | 일곱 구역과 두 위험 복도·두 우회로, 1–5일차 사건, 실패/재도전, 일시정지, 두 엔딩 |

Unity의 `Night Cafe → 편집 도구`에서 씬·프리팹·설정·스크립트를 열 수 있습니다. `InGame`의 `Night Events`에는 밤별 사건, `Passages & Doors`에는 복도와 방별 문·도착 마커, `Night Shift UI`에는 HUD와 팝업이 있습니다. 월드는 픽셀 스프라이트와 XY 평면의 2D 물리를 사용합니다.

자세한 Hierarchy와 수정 위치는 [화면 구조 안내](Docs/Presentation.md)를 참고하세요.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동, CCTV 카메라 전환, 메뉴 선택 |
| Space | 가까운 대상 조사 / 문 열기 / 선택 재료 투입 / 메뉴 실행 |
| Shift | 달리기 |
| F | 진행 방향 손전등 켜기/끄기 |
| Tab | 규칙서 열기/닫기 |
| 1–5 | 소지품 선택/해제. 소지품 버튼으로도 선택 가능 |
| E | 3일차 의자 빼 주기 / 4일차 소화기 분사 |
| 숫자 / Backspace / Enter | 암호·사고 인원 입력 / 지우기 / 확정 |

| 마우스 | CCTV, 메뉴, 문서 닫기, 소지품 선택 |

## 첫 번째 밤

감시실 책상의 CCTV를 Space로 조사하면 카페 평면도가 열립니다. 방 7곳과 통로 4곳을 지도에서 클릭하거나 WASD로 선택하면 해당 구역의 고정 카메라 영상을 실시간으로 볼 수 있습니다. 책상 우측 포스트잇은 단말기 화면에도 보입니다. CCTV를 보는 동안 캐릭터 이동은 멈추며, 감시실 밖에서는 열람할 수 없습니다.

감시실에서 로비의 홀 지름길을 거쳐 홀에 들어서면 제한 시간과 범람이 시작됩니다. 컵을 조사하고 규칙서·레시피를 대조합니다. 재료와 전자레인지는 별도 카운터 구역에 있으며 긴 작업대 옆을 돌아 접근합니다. 문의 목적지 표시는 Space로 이동하기 전에 확인할 수 있습니다.

재료는 우유·초콜릿·아몬드·타피오카·쿠킹크림입니다. 초콜릿 소스를 먼저 넣고, 전자레인지로 데운 우유를 넣어 카페모카를 만듭니다. 잘못 넣으면 시간을 줄이고 범람을 가속하며, 투입 순서만 초기화하고 이미 챙긴 재료는 유지합니다. 전자레인지의 90초 가열은 플레이용 설정에서 2초로 압축했습니다.

성공하면 타이머가 사라지고 커피가 자동으로 정리됩니다. 감시실에 다시 들어오면 1일차가 끝납니다. 시간 초과 시 실패 패널에서 사건 시점부터 재도전하며, 인벤토리·수위·시간·투입 진행도가 초기화됩니다. 컵 조사와 레시피 열람 기록은 유지됩니다.

규칙서·레시피·CCTV를 여는 동안에도 사건 시간은 흐릅니다. Esc 일시정지 메뉴만 시간을 멈춥니다.

## 두 번째 밤과 세 번째 밤

- 2일차에는 로비 메뉴판의 흔적을 조사합니다. 사건이 진행되는 동안 이동은 상하좌우로 제한되며, 반대 방향으로 한 번에 돌아서면 실패합니다. 빈 컵에 물을 받고 데운 뒤 행주에 묻혀 메뉴판을 닦습니다.
- 3일차에는 홀의 테이블 9개에 의자 18개를 뒤집어 올린 뒤 창고 칠판을 처리합니다. 분필이 멈췄을 때 지우개를 사용하고 새 마감 문구를 씁니다.
- 로비에는 `홀 지름길`과 `카운터 지름길`이 있습니다. 창고↔카운터와 숙직실↔홀에는 쓰레기 밀기 퍼즐로 여는 우회로가 있습니다. 홀↔외부↔카운터로도 이동합니다.
- 제한 시간은 2일차 5분, 3일차 6분입니다. 퍼즐과 CCTV를 보는 동안에도 시간이 흐릅니다. 실패 시 해당 밤의 감시실에서 재시작하고, 해결 후 복귀하면 다음 밤으로 이어집니다.

## 네 번째 밤

로비 CCTV의 누수를 확인하고 현장으로 가면 낙하자가 등장합니다. 소화기를 챙겨 정면에 E로 분사하면 괴물이 물러나며, 유효하지 않은 분사는 잔량을 소비하지 않습니다. 같은 전임자 노트를 읽고 창고에서 그물·고정구를 챙깁니다. 다음 일반 방에서 두 번째 추격이 시작되며 달리기 또는 남은 소화기로 탈출합니다.

다섯 일반 방 중 노란 표식 한 곳에 함정을 설치합니다. 세 번째 추격 전에는 회수·재설치가 가능합니다. 감시실 CCTV로 괴물의 방을 찾고 직접 유인하면 범위 안에서 자동 포획됩니다. 위험 복도에 들어가면 추격당 한 번씩 괴물 대치 연출 후 안전한 출구에서 이어집니다. 놓쳐도 설치 상태를 유지하며 CCTV에서 다시 찾을 수 있습니다.

## 다섯 번째 밤

꺼진 네 카메라 구역을 방문해 숫자를 찾고, 노트의 서열 순서로 숙직실 컴퓨터에 입력합니다. 복구 후 감시실에 돌아오면 시각이 멈추며 이후에는 숨겨진 제한 시간이 없습니다. 근무표·사고 기록·숙직실 CCTV를 모두 살핀 뒤 나갈 수 있습니다.

형체의 직원번호와 근무표를 대조해 맞는 명찰을 가져다줍니다. 원본 영상과 수리 요청서를 확인하고 냉장 설비 전원 끄기→정지 확인→비상 해제, 배기구 상자 제거→외부 배기 순서로 두 복도의 원인을 해결합니다. 근거에 맞춰 사고 원인·당시 잔류 인원·퇴실 상태를 정정하면 A의 쪽지를 얻습니다.

컵을 숙직실 테이블에 놓고 이름을 부릅니다. 손전등으로 영혼을 안내하고 출구를 열어 영혼이 먼저 통과하도록 한 뒤, 문 안쪽 퇴실 버튼을 누르면 마지막 회상과 감시실 에필로그로 끝납니다. 미해결 탈출·괴물 포획·세 번의 확정 오답은 CCTV 포획 엔딩입니다. 열람·영상 반복·스위치 확인에는 균열이 쌓이지 않습니다. 시간 정지 후 재도전하면 증거·소지품·해결 상태를 보존합니다.

## 개발 지점

- `Assets/Data/DayOneTuning.asset`: 밤별 제한 시간·이동·재료 순서·가열·추격·연출과 최종 단서 설정입니다. 미정 수치는 4일차 540초, 5일차 복구 360초, 미발견 300초, 복구 암호 2974, 제어함 4107, 사고 시각 02:17:36, 피해자 김서윤/A-017로 두었습니다. 확정 기획이 아닌 조정 가능한 값입니다.
- `FinalNights`: 화면과 독립된 4일차 추격·함정 상태 및 5일차 조사·설비·기록·엔딩·재도전 규칙.
- `NightStoryAuthoring` / `NightStoryContent`: 4·5일차 씬 배치와 UI 참조. 동작은 `NightGame.Hunt`, `NightGame.Investigation`, `NightGame.StoryUI`에서 처리합니다.
- `ShiftSession`: Unity 화면과 독립된 사건 상태, 인벤토리, 재료 판정, 재도전 규칙.
- `NightGame`: 입력 모드, 상호작용, 사건 진행과 저장된 화면의 상태 갱신.
- `NightGameView`: HUD·인벤토리·CCTV·문서·일시정지·결과 패널의 Inspector 참조와 버튼 연결.
- `NightPlayer`: Input System 기반 XY 평면 이동, Rigidbody2D·CircleCollider2D 충돌, 스프라이트 손전등, 재료 투입 애니메이션.
- `CafeWorld`: 씬에 배치된 플레이어·컵·범람·상호작용 대상의 참조. `CafeWorld.prefab` 안에서 방·가구·문·재료를 편집합니다.
- `StartScreen`: 저장된 메뉴의 입력·버튼 선택·도움말 표시·씬 전환.
- `CafeUi` / `CafeButtonStyle`: 공통 색상, 창 설정, 이미지 기반 버튼 선택 표현.
- `NightCampaignAuthoring`: 2·3일차 씬 소품, 복도와 2D 충돌, 우회문 UI를 배치합니다.
- `Assets/Editor/*Authoring.cs`: 필요할 때만 실행하는 에디터 전용 초기 제작 도구.

한글은 프로젝트에 포함한 나눔고딕을 사용합니다. 손전등은 이동 화면 위의 방향 마스크로 실제 보이는 범위를 제한하며 CCTV 시야에는 적용하지 않습니다.

## 검증과 빌드

Unity 메뉴의 `Night Cafe/Validate All Five Nights`로 다섯 밤의 규칙·실패·재도전·함정 후보·설비 순서·두 엔딩과 우회 퍼즐 해법을 검사합니다. `Night Cafe/Build Windows FHD`로 두 씬을 Windows x64 개발 빌드로 생성합니다.

`Night Cafe/Rebuild Authored Scenes` 또는 `Rebuild Foundation Scenes`는 다섯 밤을 포함한 2D 씬과 UI를 다시 저장합니다. 기존 씬은 `Artifacts/SceneBackups`에 백업합니다. 일반 작업에는 기존 씬·프리팹을 직접 편집하세요. 제작 도구를 다시 실행하면 해당 씬·프리팹의 수동 편집을 초기화합니다.

개발용 실행 검증은 `NightCafe.exe -foundationSmokeTest -testArtifacts <절대경로>`입니다. Windows 플레이어에서 다섯 밤을 연속 진행하며 실제 입력·UI·방별 표시·상호작용 접근성·추격·재도전·설비·기록·동행과 두 엔딩을 확인합니다. 지정 폴더에 스크린샷·로그·결과를 남긴 뒤 종료합니다.
