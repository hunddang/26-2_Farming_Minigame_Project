# 이상현상 퇴마 기록

Unity 6000.3.18f1 기반의 Windows 64비트, FHD 1920×1080 창 모드 게임 토대입니다. `tmp`의 전체 기획과 2026-10-25 작성된 1일차 시스템 기획을 읽고, 구체화된 1일차 흐름을 우선 구현했습니다.

## 실행

- Unity Hub에서 `Unity` 폴더를 프로젝트로 엽니다.
- `Assets/Scenes/Lobby.unity`를 열고 Play를 누릅니다.
- Windows 빌드가 있는 경우 `Builds/Windows/NightCafe.exe`를 실행합니다. 배포할 때는 `Windows` 폴더 전체를 함께 전달합니다.
- Game 뷰는 1920×1080 또는 16:9로 설정합니다. 실행 파일은 FHD 고정 크기 창으로 시작합니다.

## 두 씬

| 씬 | 역할 |
| --- | --- |
| Lobby | 게임 시작 화면, 조작 안내, 종료 |
| InGame | 감시실·로비·카페·창고·숙직실, 사건, 실패/재도전, 일시정지, 1일차 완료 |

추가 씬은 없습니다. 결과와 문서, CCTV는 인게임 Canvas의 패널로 표시합니다. 씬의 루트 컴포넌트가 플레이 시작 시 맵과 UI를 생성하며, 모든 화면은 FHD Canvas 기준입니다. 현재 시각 요소는 외부 에셋 없이 코드로 생성한 회색상자 단계의 도형입니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동, CCTV 카메라 전환, 메뉴 선택 |
| Space | 가까운 대상 조사 / 문 열기 / 선택 재료 투입 / 메뉴 실행 |
| Shift | 달리기 |
| F | 진행 방향 손전등 켜기/끄기 |
| Tab | 규칙서 열기/닫기 |
| 1–5 | 소지품 선택/해제. 소지품 버튼으로도 선택 가능 |
| Esc | 문서·CCTV 닫기 / 일시정지 / 계속 |
| 마우스 | CCTV, 메뉴, 문서 닫기, 소지품 선택 |

## 첫 번째 밤

감시실 책상의 CCTV를 Space로 조사하면 실제 맵을 비추는 카메라 화면이 열립니다. 카페 홀·감시실·창고·숙직실을 전환할 수 있고, CCTV 중에는 캐릭터 이동이 멈춥니다. 이동 화면에는 현재 방의 사물만 보이고 다른 방은 평면도만 보입니다. 감시실을 떠나면 원격으로 사물을 관찰할 수 없습니다. 컵 근처 또는 카페 CCTV에서 컵의 달그락거리는 소리를 들을 수 있습니다.

감시실의 아래쪽 문을 열고 로비를 지나 오른쪽 카페 문을 엽니다. 카페에 들어서면 제한 시간과 범람이 시작됩니다. 컵을 먼저 조사하고, 규칙서와 카페 바닥의 레시피를 읽어 해결 방법을 판단합니다. 제조 공간은 긴 카운터의 왼쪽이나 오른쪽을 돌아 들어갑니다.

재료는 우유·초콜릿·아몬드·타피오카·쿠킹크림 다섯 종류입니다. 재료를 모아 선택한 뒤 컵 앞에서 Space를 누르면 팔을 뻗는 동작을 간단히 표현한 짧은 애니메이션 후 사용됩니다. 정답은 기본 설정에서 우유 → 초콜릿입니다. 틀린 재료나 순서는 즉시 사망시키지 않고 시간을 줄이고 잠시 범람을 가속합니다. 투입 순서는 초기화되고, 사용한 재료는 제조 공간에서 다시 얻을 수 있습니다.

성공하면 타이머가 사라지고 커피가 자동으로 정리됩니다. 감시실에 다시 들어오면 1일차가 끝납니다. 시간 초과 시 실패 패널에서 사건 시점부터 재도전하며, 인벤토리·수위·시간·투입 진행도가 초기화됩니다. 컵 조사와 레시피 열람 기록은 유지됩니다.

규칙서·레시피·CCTV를 여는 동안에도 사건 시간은 흐릅니다. Esc 일시정지 메뉴만 시간을 멈춥니다.

## 개발 지점

- `Assets/Data/DayOneTuning.asset`: 제한 시간 180초, 오답 20초, 5초간 2배 범람, 이동 속도, 상호작용 거리, 3초 자동 정리, 재료 순서. 기획의 미정 항목에 대한 임시 값입니다.
- `ShiftSession`: Unity 화면과 독립된 사건 상태, 인벤토리, 재료 판정, 재도전 규칙.
- `NightGame`: 입력 모드, 상호작용, 사건 진행, CCTV·문서·HUD·결과 화면.
- `NightPlayer`: Input System 기반 이동과 물리 충돌, 달리기, 방향 손전등.
- `CafeWorld`: 방 연결, 가구·벽·문·재료 배치와 도형 표현. 최종 아트·프리팹으로 교체할 지점입니다.
- `StartScreen` / `CafeUi`: 시작 화면, 1920×1080 UI와 Windows 한글 시스템 글꼴.

한글은 Windows의 맑은 고딕을 사용합니다. 현재 손전등은 방향을 보여 주는 도형 표현이며, 시야 차폐·광원 기반 암전은 후속 작업입니다. 2–5일차, 복도 괴물, 우회 퍼즐, 최종 아트·익사 애니메이션은 이번 1일차 기반에 포함하지 않았습니다.

## 검증과 빌드

Unity 메뉴의 `Night Cafe/Validate Day One Rules`로 상태·재료 순서·오답 페널티·가속 시간 경계·실패·재도전·자동 정리·복귀 조건을 검사합니다. `Night Cafe/Build Windows FHD`로 두 씬만 Windows x64 개발 빌드를 생성합니다.

`Night Cafe/Rebuild Foundation Scenes`는 두 씬을 초기 부트스트랩으로 다시 저장하는 도구입니다. 씬을 직접 편집한 뒤에는 이 명령을 사용하면 해당 씬 편집을 덮어쓰므로, 일반 작업에는 기존 씬을 그대로 사용합니다.

개발용 실행 검증은 `NightCafe.exe -foundationSmokeTest -testArtifacts <절대경로>`입니다. 실제 플레이어에서 FHD·두 씬·CCTV 입력 분리·문 충돌·사건 시작·문서 중 시간·오답·일시정지·실패·재도전·정답·자동 정리·복귀 완료를 검사하고 스크린샷과 결과를 지정 폴더에 남긴 뒤 종료합니다. 검증 모드는 일반 실행에서 동작하지 않습니다.
