# 이상현상 퇴마 기록

Unity 6000.3.18f1 / URP 기반의 Windows 64비트, FHD 1920×1080 창 모드 3D 게임입니다. `tmp`의 전체 기획과 2026-10-25 작성된 1일차 시스템 기획을 읽고, 구체화된 1일차 흐름을 우선 구현했습니다.

## 실행

- Unity Hub에서 `Unity` 폴더를 프로젝트로 엽니다.
- `Assets/Scenes/Lobby.unity`를 열고 Play를 누릅니다.
- Windows 빌드가 있는 경우 `Builds/Windows/NightCafe.exe`를 실행합니다. 배포할 때는 `Windows` 폴더 전체를 함께 전달합니다.
- Game 뷰는 1920×1080 또는 16:9로 설정합니다. 실행 파일은 FHD 고정 크기 창으로 시작합니다.

## 두 씬

| 씬 | 역할 |
| --- | --- |
| Lobby | 게임 시작 화면, 조작 안내, 종료 |
| InGame | 감시실·로비·카페·창고·숙직실, 사건, 실패/재도전, 일시정지, 1일차 완료 |

추가 씬은 없습니다. 맵, 카메라, UI와 비활성 팝업을 씬·프리팹에 저장했습니다. Play 전에도 Hierarchy에서 위치·이미지·텍스트·충돌 영역을 편집할 수 있습니다. UI는 기존 FHD Canvas를 유지합니다. 월드는 `Assets/Art/NightCafe3D`의 직접 제작한 로우폴리 모델·메시·재질과 3D 물리를 사용합니다. 기존 픽셀 아트는 UI 아이콘 등에 유지됩니다. 씬 수, 방 배치, 상호작용 위치, 조작과 1일차 판정·진행 규칙은 유지했습니다.

자세한 Hierarchy와 수정 위치는 [화면 구조 안내](Docs/Presentation.md)를 참고하세요.

## 첫 번째 밤

감시실 책상의 CCTV를 Space로 조사하면 실제 3D 공간을 촬영하는 별도 원근 카메라 화면이 열립니다. 각 방 벽 위에 설치된 CCTV 렌즈 위치와 방향을 사용하고, 1280×720 RenderTexture를 UI 화면으로 실시간 전달합니다. 카페 홀·감시실·창고·숙직실을 전환할 수 있고, CCTV 중에는 캐릭터 이동이 멈춥니다. 일반 화면은 북쪽이 화면 위에 오는 비스듬한 원근 추적 시점입니다. 현재 방의 사물만 보이고 다른 방은 바닥·낮은 벽만 보입니다. 일반 화면에서는 벽을 낮게 표시해 캐릭터 가림을 줄이고, CCTV에서는 실내 벽과 천장을 표시합니다. 감시실을 떠나면 원격으로 사물을 관찰할 수 없습니다. 컵 근처 또는 카페 CCTV에서 컵의 달그락거리는 소리를 들을 수 있습니다.

감시실의 아래쪽 문을 열고 로비를 지나 오른쪽 카페 문을 엽니다. 카페에 들어서면 제한 시간과 범람이 시작됩니다. 컵을 먼저 조사하고, 규칙서와 카페 바닥의 레시피를 읽어 해결 방법을 판단합니다. 제조 공간은 긴 카운터의 왼쪽이나 오른쪽을 돌아 들어갑니다.

재료는 우유·초콜릿·아몬드·타피오카·쿠킹크림 다섯 종류입니다. 재료를 모아 선택한 뒤 컵 앞에서 Space를 누르면 팔을 뻗는 동작을 간단히 표현한 짧은 애니메이션 후 사용됩니다. 정답은 기본 설정에서 우유 → 초콜릿입니다. 틀린 재료나 순서는 즉시 사망시키지 않고 시간을 줄이고 잠시 범람을 가속합니다. 투입 순서는 초기화되고, 사용한 재료는 제조 공간에서 다시 얻을 수 있습니다.

성공하면 타이머가 사라지고 커피가 자동으로 정리됩니다. 감시실에 다시 들어오면 1일차가 끝납니다. 시간 초과 시 실패 패널에서 사건 시점부터 재도전하며, 인벤토리·수위·시간·투입 진행도가 초기화됩니다. 컵 조사와 레시피 열람 기록은 유지됩니다.

규칙서·레시피·CCTV를 여는 동안에도 사건 시간은 흐릅니다. Esc 일시정지 메뉴만 시간을 멈춥니다.

## 개발 지점

- `Assets/Data/DayOneTuning.asset`: 제한 시간 180초, 오답 20초, 5초간 2배 범람, 이동 속도, 상호작용 거리, 3초 자동 정리, 재료 순서. 기획의 미정 항목에 대한 임시 값입니다.
- `ShiftSession`: Unity 화면과 독립된 사건 상태, 인벤토리, 재료 판정, 재도전 규칙.
- `NightGame`: 입력 모드, 상호작용, 사건 진행과 저장된 화면의 상태 갱신.
- `NightGameView`: HUD·인벤토리·CCTV·문서·일시정지·결과 패널의 Inspector 참조와 버튼 연결.
- `NightPlayer`: Input System 기반 XZ 평면 이동, Rigidbody·CapsuleCollider 충돌, 달리기, Spot Light 손전등과 보행·팔 뻗기 애니메이션.
- `CafeWorld`: 씬에 배치된 플레이어·컵·범람·상호작용 대상의 참조. `CafeWorld.prefab` 안에서 방·가구·문·재료를 편집합니다.
- `StartScreen`: 저장된 메뉴의 입력·버튼 선택·도움말 표시·씬 전환.
- `CafeUi` / `CafeButtonStyle`: 공통 색상, 창 설정, 이미지 기반 버튼 선택 표현.
- `Assets/Editor/Cafe3DAssets.cs`: 직접 제작한 22종의 모델, 공유 메시와 재질을 저장하는 제작 도구.
- `Assets/Editor/Cafe3DConversion.cs`: 기존 월드의 위치·참조를 유지하는 3D 변환 및 화면 검증 도구. 일반 플레이에서 월드를 생성하지 않습니다.
- `Assets/Editor/*Authoring.cs`: 필요할 때만 실행하는 에디터 전용 초기 제작 도구.

한글은 프로젝트에 포함한 나눔고딕을 사용합니다. 글꼴 라이선스는 `Assets/Art/Fonts/OFL.txt`에 있습니다. 손전등은 실제 Spot Light로 바꾸었으며, 가구와 벽의 3D 그림자를 사용합니다. 2–5일차, 복도 괴물, 우회 퍼즐, 익사 애니메이션은 이번 1일차 기반에 포함하지 않았습니다.

## 검증과 빌드

Unity 메뉴의 `Night Cafe/Validate Day One Rules`로 상태·재료 순서·오답 페널티·가속 시간 경계·실패·재도전·자동 정리·복귀 조건을 검사합니다. `Night Cafe/Build Windows FHD`로 두 씬만 Windows x64 개발 빌드를 생성합니다.

`Night Cafe/Validate 3D Presentation`으로 3D 메시·충돌·재질과 네 CCTV 위치를 검사할 수 있습니다.

`Night Cafe/Rebuild Authored Scenes` 또는 기존 `Rebuild Foundation Scenes`는 기존 3D 월드 프리팹을 사용해 두 씬과 UI를 다시 저장합니다. 기존 씬은 `Artifacts/SceneBackups`에 백업합니다. 3D 변환 전 씬·월드·플레이어·시작 UI는 `Artifacts/3DBackups`에 보관합니다. 일반 작업에는 기존 씬·프리팹을 직접 편집하세요. 이 제작 도구를 다시 실행하면 해당 씬·프리팹의 수동 편집을 초기화합니다.

개발용 실행 검증은 `NightCafe.exe -foundationSmokeTest -testArtifacts <절대경로>`입니다. 실제 플레이어에서 FHD·두 씬·CCTV 입력 분리·문 충돌·사건 시작·문서 중 시간·오답·일시정지·실패·재도전·정답·자동 정리·복귀 완료를 검사하고 스크린샷과 결과를 지정 폴더에 남긴 뒤 종료합니다. 검증 모드는 일반 실행에서 동작하지 않습니다.
